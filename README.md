- Upstream: https://github.com/langchain-ai/agent-protocol
- License: MIT
- Source API description: `upstream/openapi.json`
- Generator: Sourcey 3.6.12

The pinned upstream commit and commit date are recorded in `evidence.json`.

## Rebuild

```powershell
npx -y sourcey@3.6.12 build .\upstream\openapi.json --output .\site
```

The generated site is committed under `site/` so the public GitHub Pages artifact is directly inspectable and reproducible from the pinned OpenAPI input.

This repository is an independent community documentation artifact and is not an official LangChain publication.
